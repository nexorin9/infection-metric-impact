# 运维排障通道 · 参数参考

本工具以桌面窗口为主入口；命令行只服务两类场景：**无人值守跑批**（CI、定时任务）与**出问题时排障**。日常业务操作请用桌面窗口。

## 通道一览

| 命令 | 用途 | 是否需要凭据 | 典型调用方 |
|------|------|--------------|------------|
| `./run.sh` | 启动桌面窗口（三栏 + 托盘常驻） | 是 | 院感科办公 PC |
| `./run.sh --headless` | 跑一次复算并打印运行摘要 | 是 | 定时任务 / CI |
| `./run.sh --doctor` | 配置项、凭据位、端点可达性、本地库可读写自检 | 否 | 部署后首跑 / 排障 |
| `./run.sh --offline-sample` | 离线演示：读仓库内置脱敏样例 | 否 | 无凭据环境下的功能确认 |
| `./run.sh --help` | 打印参数说明 | 否 | — |

## 行为约定

- **默认路径指向真实端点**。`--offline-sample` 是显式开关的演示通道，不会被默认启动路径引用。
- **令牌不回显**。自检回显对令牌类配置项只显示「已配置（长度 N）」。
- **失败不静默**。任一通道失败时以非零码退出并打印可读原因，不写半截产物。
- **无图形界面时**：`./run.sh` 检测到 headless 环境会提示改用 `--headless` 或 `--doctor`，不抛异常栈。

## 退出码

| 退出码 | 含义 |
|--------|------|
| `0` | 正常完成 |
| `1` | 启动或运行期失败（异常已打印可读原因） |
| `2` | 内置离线样例缺失或不可读 |
| `3` | 当前环境无图形界面，无法启动桌面窗口 |

## 环境变量装载

`run.sh` 启动时若同目录存在 `.env`，会自动装载（`set -a` 方式导出）。**已在环境中的同名变量优先**，不会被 `.env` 覆盖——这样 CI 或 systemd 注入的凭据始终优先于本地文件。

`.env` 不进版本库（`.gitignore` 已排除 `.env`），仓库内只保留 `.env.example`（13 个变量名与示例格式，无真实值）。

## 退出后仍需确认的两件事

1. `--headless` 落盘的 `out/runs/<年度>/<运行标识>/summary.json` 里 `failed_steps` 是否为空——非空说明有指标复算失败，需按其中给出的可读原因处理，**不要**把失败当 0。
2. `--doctor` 的「端点可达性」一段：返回 `HTTP 401/403` 说明地址通但令牌无效或未配置，需先补凭据位再跑正式任务。
