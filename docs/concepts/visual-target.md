# 视觉目标卡 · 院感指标口径影响分析

> 本环境**不具备图像生成能力**，因此本目录**只保留结构化视觉目标卡**，不伪造概念图、不放占位图。
> 真实运行截图由 Phase 4 收尾任务采集到 `docs/screenshots/`；README 的「概念 / 实测对照」小节必须诚实标注
> **左侧＝本卡（视觉目标）、右侧＝实测截图**，不得声称两者一致。

## 1. 三个状态

**起始态**
主窗口打开即见左栏「口径库」树（主题域 → 指标 → 版本，每行带状态标签：已发布 / 草稿 / 待复核），
空态提示「本院尚无口径条目，可从制度文件导入或手工新建」；右下角托盘常驻，一行灰字
「上次复算：昨天 22:10 · 无差异」。

**首个可用瞬间**
选中「医院感染发生率」→ 右栏立刻出现「本季度 分子 12 / 分母 1,480 / 按口径 v3（生效 2026-07-01）」；
一条琥珀色提示条横在下方：「分母被 3 个指标复用；改了会影响 2026Q2、2026Q3 已上报值」，旁边一个
「查看受影响指标」按钮；拖动「排除条件」后依赖树立刻展开成两跳。

**成形态**
三栏布局——左「口径库树」、中「依赖图 / 影响面清单」、右「差异说明（分子差 / 分母差 / 口径差三段）+
待主任确认项」；底部日志区滚动「按 v4 复算 2026Q3 → 12/1478 → 差异 +2 例 → 待主任确认」；
右上托盘气泡弹「3 项口径待复核」。

## 2. 画面类型

**桌面窗口 + 系统托盘**（匹配本轮锁定的交付形态「桌面常驻小工具」）。
Java + Swing：`JSplitPane` 三栏 + `JTree` 口径库 + `JTable` 影响面清单 + `JTextArea` 日志区 +
`java.awt.SystemTray` 托盘图标与气泡。**不写**成本地 CLI 表格，也不做 Web 控制台。

## 3. 视觉语言

| 项 | 取值 |
|----|------|
| 背景 | `#F5F7FA` |
| 面板 | `#FFFFFF` |
| 主色（医院蓝） | `#1B6CA8` |
| 分隔线 | `#DDE3EA` |
| 正文 | `#1F2933` |
| 次要文字 | `#6B7A8C` |
| 状态标签 · 草稿 | `#B7791F` |
| 状态标签 · 待复核 | `#C05621` |
| 状态标签 · 已发布 | `#2F855A` |
| 状态标签 · 已停用 | `#718096` |
| 差异提示底色 | `#FFF8E6` |

- **字体族**：中文 UI 字体（PingFang SC / Microsoft YaHei）12–13px；**数字用等宽 tabular 字体**
  （Consolas / JetBrains Mono），保证分子分母上下对齐可对拍；差异数字 16px 加粗。
- **信息层级**：**右栏「差异说明」最显眼**（大号数字 + 三段式对照）→ 左树次之 → 底部日志最弱（11px 灰）。
- **留白密度**：中等，16px 栅格，表格行高 28px，栏间 1px 分隔线而非阴影。

## 4. 必须可达的约束

- 只用 JDK 自带 Swing 组件 + 本地文件型口径库（JSON）；不引入重型 ORM。
  依赖图用 `JTree` 缩进 + `JPanel.paintComponent` 自绘连线，**不引入第三方图框架**；
  热力图 / 3D / WebGL 一律不画。
- 截图方式：Java `Robot` 或离屏渲染（`java.awt.headless`）截真实窗口，落 `docs/screenshots/`。
- 本卡是**设计意图**；实际实现允许在信息密度与配色细节上与之有差距，差距以 `docs/screenshots/`
  里的真实截图为准。
